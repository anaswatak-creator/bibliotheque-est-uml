\# Projet BibliothequeEST



\## Description

Ce projet contient le modèle conceptuel et l'arborescence de travail pour la gestion d'une bibliothèque, réalisé dans le cadre du TP de modélisation UML.



\## Auteur

\* \*\*Nom :\*\* Anas Watak

\* \*\*Filière :\*\* Data Science et Intelligence Artificielle (SDIA - S2)

\* \*\*Établissement :\*\* École Supérieure de Technologie (EST)



\## Structure du projet

\* `model/` : Contient le fichier source StarUML (`bibliotheque.mdj`).

\* `docs/` : Réservé pour la documentation du projet.

\* `src/` : Réservé pour les éventuels codes sources ou scripts.
